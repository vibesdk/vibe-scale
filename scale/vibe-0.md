Vibe-Scale 0 projects are written entirely by humans. No agentic coders, code generators, or test generators contributed to what landed in the repository. Incidental use of an LLM as a reference (asking a question, looking up an API) is not what this badge is about — the focus is whether code or tests were produced by a model rather than written by a person.

Because [V is the root multiplier in the score formula](https://github.com/vibesdk/vibe-scale/blob/main/README.md#algorithm), a project with no AI always scores 0 regardless of how its code is reviewed or tested. The badge speaks only to provenance, not to quality: a Vibe-Scale 0 project may be exhaustively tested or barely tested at all.

Authors typically declare Vibe-Scale 0 to make a clear statement about the origin of their code — for licensing or training-data concerns, regulatory constraints, or a deliberate engineering preference for human-only authorship.
